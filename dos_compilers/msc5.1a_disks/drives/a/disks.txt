Microsoft C 5.1 and MASM 5.1
March 1988

Eleven 3.5" DD floppies.

Shipped with MS OS/2 SDK 1.03 or possibly also with later SDK updates.

Note: This disk set is almost identical to retail Microsoft C 5.1
and MASM 5.1. The main difference is that both products were combined
into a single set and QuickC was removed (despite the label of one
disk explicitly advertising QuickC).
