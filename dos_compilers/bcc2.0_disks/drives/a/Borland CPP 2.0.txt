Borland C++ 2.0
Released in 1991 by Borland
For DOS

Image quality: Unmodified/No write tab

Borland C++ targeted the professional application development market,
while Turbo C++ targeted the home and hobbyist market. Borland C++
included additional tools, compiler code-optimization, and
documentation to address the needs of commercial developers. In 1997
Borland C++ was replaced with Borland C++ Builder.

There was no "Borland C++ 1.0", it started at 2.0, possibly to
differentiate itself from Turbo C++.
