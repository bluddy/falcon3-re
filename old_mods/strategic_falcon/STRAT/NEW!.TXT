 
                        Strategic FALCON
                       Version 1.1 Update
                      
    This file is just a cursory overview of the new features in 
    version 1.1.  See the 11_READ.ME file for full information!
                    

                      New! in Version 1.1:

-Sim Mode!  Strategic Falcon is now awash in strategy!
                      
-Loadouts!  No more overloaded planes!
                      
-Speed limits will now be enforced!
 
-Updated for Falcon 3.05.
 
-One key brings you to Falcon!  <F4> starts Falcon, and when you 
 exit, you'll be back in StratFalc again (even works while in 
 the KCC menu program!).
                                      
-Added "Perfect" button to the pilot's dialog to allow you to instantly
 set all attributes to 100.

-The mouse interrupt has been tweaked to speed up mouse movement--
 use the "/NOSPEEDUP" switch on startup if you prefer the old method.
 
-K Boxes (Kill Boxes) takes the place of Nums on the main screen.  
 This is a little more helpful than site numbers.  You can still see
 the numbers, however, if you go to OTHER/MAP.
 
-You can now instantly switch your first Falcon flight with any other
 flight.  Just hit <F3>.

-In the "Where?" mode, the right mouse button will now cause an exit
 to normal mode, and the "Esc" key will also now do so properly.

-StratFalc now compensates for Falcon's annoying habit of deducting 
 your fuel after you exit Falcon from the cockpit.

-RESTRCAM.BAT has been updated--be sure to copy it to your 
 Falcon directory.
 
-Fixed occasional heap allocation problem with opening files.
 
-Victory/Defeat nodes in Kuwait can now be properly selected.

-Fixed problem where StratFalc was setting the DOS VERIFY flag 
 and not resetting it to its original state (thereby causing 
 disk access slowdown).            
 
-Fixed problem where allied flights were being limited to an 
 altitude of about 30,000 feet.
 
-Available aircraft in Bosnia have been updated to reflect what 
 you can really put there--just about everything!

-<F1> brings up a screen that shows the Function key assignments.

-<ALT-X> now exits StratFalc.

-The "Timing Trace" controls have been changed.

-Put a new limiter on StratFalc flights to better reflect what Falcon
 actually places in the theater--total aircraft is now 14, not 16 as
 stated in the manual.

-You can now tell StratFalc to shut up.  If you start it with 
 the "/NOSOUND" (i.e., "STRAT /NOSOUND") switch it won't make a 
 peep no matter how badly you confuse it.

-If the map is zoomed in over a certain amount, and you change 
 waypoints using the "+/-" button, StratFalc will automatically 
 slew the map so the new waypoint is centered.
