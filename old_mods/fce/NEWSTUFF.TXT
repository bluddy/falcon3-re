Complete version history for FCE:

Version 1.3: 9 JUL 95
	Allow selection of printer font (should solve MOST printer problems)
	Reverse Red Flag missions: turn RF mission into campaign mission
	Edit attributes of strategic sites
	Permanently fixed fuel calc bug from v1.1
	Arrival times more accurate (fixed roundoff error)
	Changes to pilot medals now saved
	More detail in flight printouts
	New look for Time-on-Target
	Main window contains an F-16
	Major code restructuring (shouldn't affect users)

Version 1.2: 15 OCT 94
	Support all features for Hornet
	Use files from CD for partial install
	Print pilot names on flight sheets
	Windows should now print to all types of printers

Version 1.1a: 11 SEP 94 (later in the day)
	RF Remap didn't work unless you had Falcon, MiG, and OFT.
	  It now ignores missing files.
	Compiled correctly so that Windows fuel calc works.

Version 1.1:  11 SEP 94
	Two fixes to fuel calculation routine
	Allow editing of Hornet Roster/Squadron
	Added printing of squadron/flight
	Added generation of "Enemy Report" (Red Flag Mission)

Version 1.0:  1 MAR 94
	Introduced Windows interface
	Update Sierra Hotel
	Batch operation with /S implemented
	Fuel calculation implemented

Version 0.9:
	Original version.
	DOS only, no Windows
